# Checkpoint V123 · cinco Códigos Caja y práctica diferida contemporánea

V123 cierra el puente público de identificadores para las cinco especies objetivo. Dos estados contables bancarios de 2009 confirman `5326` para el cupón 15 separado `ARARGE03G415`; Banco Columbia, además, rotula expresamente la columna `Identificación Caja de Valores` y muestra en la misma tabla 5426, 5427, 45698 y 45701. Esto identifica especies, no prueba liquidación.

La modalidad diferida también queda mejor delimitada. No se localizó una edición fechada explícitamente como vigente en 2008.
