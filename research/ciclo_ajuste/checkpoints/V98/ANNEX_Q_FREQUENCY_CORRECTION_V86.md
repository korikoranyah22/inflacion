# Annex Q frequency correction — V86

## Correction

The recovery queue had been phrased as if a quarterly **“Annex Q 9M”** should exist. That target was wrong.

BCRA Communication A 7809, section 12, row 25, defines **“Anexo Q - Apertura de Resultados (A-Q)”** with frequency **ANUAL** and **NO COMPARATIVO**.

Therefore the strict 9M retrieval target is not a nonexistent quarterly Annex Q. For 30/09/2023 the valid routes are:

1. the separated interim interest-income / interest-expense notes and exhibits;
2. an official entity-specific subaccount-to-presentation mapping; or
3. another primary regulatory artifact that explicitly exhausts the four counterparty legs.

This changes only the retrieval terminology/strategy. It does **not** alter any frozen V85 number.

Official source: https://www.bcra.gob.ar/archivos/Pdfs/comytexord/A7809.pdf
