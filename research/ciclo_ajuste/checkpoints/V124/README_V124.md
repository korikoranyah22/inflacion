# Checkpoint V124 · edición SLIQ 2000 y cadena operativa preobjetivo

V124 corrige un límite importante de V123: el manual `Sistema de Transferencias Electrónicas` sí tiene fecha interna. Su página legal dice `Impreso en Buenos Aires, Marzo de 2000`. El mismo manual define inmediata, diferida, matching, confirmación, almacenamiento provisorio y procesamiento nocturno.

La cadena temporal se amplía con tres fuentes primarias nuevas. Una página institucional del Merval archivada el 08/02/2004 ofrecía el sistema y su documentación; la memoria de Caja del ejercicio 2006 documenta infraestructura y actividad por transferencias; y el manual paralelo MU-32002.03 conserva una tabla de revisiones 2006/2007/2009 que demuestra el tipo de control documental que debe buscarse para SLIQ/SCG.

Esto fecha la edición y prueba disponibilidad del sistema antes de 2008, pero no demuestra qué revisión estaba vigente en cada ronda ni acredita una liquidación objetivo.
