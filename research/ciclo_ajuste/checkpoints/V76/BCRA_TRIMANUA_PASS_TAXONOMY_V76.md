# BCRA TRIMANUA pass taxonomy — V76

## Finding

Communication A 7749 (24-Apr-2023; effective 25-Apr-2023) rewrote Section 12, **Estados Financieros para publicación trimestral/anual**, for the migration of states/annexes to `TRIMANUA.TXT` (design 4401), with effect for the quarter begun 1-Apr-2023 and ended 30-Jun-2023.

For our four-leg pass target, the standard reporting codes are:

- `0301060100` — income / pass operations / **Banco Central de la República Argentina**
- `0301060200` — income / pass operations / **Otras entidades financieras**
- `0302030100` — expense / pass operations / **Banco Central de la República Argentina**
- `0302030200` — expense / pass operations / **Otras entidades financieras**

Parent codes are `0301060000` (income from pass operations) and `0302030000` (expense from pass operations).

## Consequence for the recovery gate

The 9M target no longer depends on finding an Annex Q PDF. An issuer note or regulatory extract is compatible if it reproduces these same four flow/counterparty concepts on the target individual/separate basis and can be reconciled to the entity FY Annex Q. This formalizes the Credicoop V75 path and becomes the primary recovery pattern for BNA/BAPRO/Ciudad.
