# Annex Q interim availability nuance — V88

V86 correctly established that BCRA Communication A 7809 lists Annex Q with **annual required frequency**. V88 adds an important nuance: this does **not** mean an issuer can never publish an interim Annex Q.

Banco Comafi's official separated 30/09/2023 package voluntarily includes **“Anexo Q - Apertura de Resultados”** and explicitly opens the four pass legs at 9M.

Operational rule going forward:

- do not assume or require an Annex Q at every quarter;
- do not describe 9M Annex Q as normatively mandatory;
- if an issuer voluntarily publishes one, it is valid primary evidence and can be used after basis/period checks.
