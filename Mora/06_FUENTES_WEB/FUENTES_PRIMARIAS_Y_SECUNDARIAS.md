## Fuentes secundarias del documento base

Las notas de TN, Infobae, La Nación y La Izquierda Diario se utilizaron para contexto parlamentario y político. DeQuéSeTrata se usó para identificar expedientes. Scribd sirvió como pista de recuperación. Ninguna fuente secundaria reemplaza el texto oficial del proyecto ni los datos del BCRA.

## Regla de evidencia

1. texto oficial vigente antes que resumen;
2. dato del organismo productor antes que nota periodística;
3. unidad y período explícitos;
4. separación entre hechos, cálculos e inferencias;
5. correlación nunca presentada como causalidad; y
6. toda contradicción queda visible, no se resuelve por conveniencia argumental.
